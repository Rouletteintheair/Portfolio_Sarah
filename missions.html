Mes missions

Mission 1

Configuration de la supervision réseau (NetFlow) sur des switchs cisco pour faire remonter l'analyse du trafic vers l'outil de monitoring Auvik

Objectif

• Le besoin : L'entreprise avait besoin d'une visibilité approfondie sur le trafic réseau (qui consomme de la bande passante, quels protocoles sont utilisés, détection d'anomalies). • La solution : Configurer le protocole NetFlow sur les commutateurs pour envoyer des statistiques de flux vers la solution de supervision cloud Auvik. • L'environnement technique : ○ Commutateurs Cisco Catalyst 9300 (ex: FRLIL-LTP1S-1-CS9300-EDF-FELIX-1). ○ Accès physique en salle serveur (baies de brassage) et connexion en console via PuTTY.

Actions réalisées

  • • Étape 1 : Création des "Flow Records" (Enregistrements)
    • ○ Explication : J'ai défini les critères de capture (adresses IP source/destination, ports TCP/UDP) et les compteurs (nombre d'octets et de paquets) pour le trafic entrant (AuvikInputRecord) et sortant (AuvikOutputRecord).
  • • Étape 2 : Configuration des "Flow Monitors" (Moniteurs)
    • ○ Explication : J'ai configuré la destination d'envoi des données. ○ Données clés : Envoi vers l'IP du collecteur Auvik (192.168.14.200) via le port UDP 2055.
  • • Étape 3 : Vérification de la transmission des données vers Auvik
    • ○ Explication : J'ai lié les Records créés à l'étape 1 avec l'Exporter créé à l'étape 2.
  • • Étape 4 : Application sur les interfaces réseau
    • ○ Explication : J'ai appliqué ces moniteurs sur l'interface virtuelle appropriée (ici le vlan 913) pour qu'il commence à analyser le trafic réel.
  • • Étape 5 : Sauvegarde de la configuration
    • ○ Action : Exécution de la commande copy running-config startup-config pour s'assurer que la configuration survive à un redémarrage électrique du switch.
